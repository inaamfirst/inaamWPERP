Displays product videos managed and synchronized by ChoiceOye ERP.

== Description ==

ChoiceOye ERP Product Videos appends synchronized MP4, YouTube, and Vimeo videos
to WooCommerce product galleries. Video editing remains in ChoiceOye ERP.

== Installation ==

1. Upload and activate the plugin ZIP.
2. Ensure WooCommerce 8.5 or newer is active.
3. In ChoiceOye ERP, save the WooCommerce and WordPress media credentials.
4. Test the connection and run a product synchronization.

Removing a video from a product does not delete its WordPress Media Library file.
